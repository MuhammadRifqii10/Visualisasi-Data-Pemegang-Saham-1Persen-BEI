# Visualisasi-Data-Pemegang-Saham-1Persen-BEI
Project visualisasi data pemegang saham Bursa Efek Indonesia (BEI) menggunakan Python, Pandas, Matplotlib, dan Google Colab.

# Dataset
Dataset yang dianalisis terdiri dari 500 baris data dan 10 kolom. Dataset ini digunakan untuk keperluan pembelajaran dan visualisasi data, sehingga tidak mewakili seluruh data pemegang saham BEI.

# Visualisasi

Perbandingan investor lokal dan asing.
Sepuluh kode saham dengan total kepemilikan terbesar.
Sepuluh investor dengan persentase kepemilikan terbesar.

# Hasil

Visualisasi membantu memahami komposisi investor dan membandingkan informasi kepemilikan saham dalam dataset yang dianalisis.
